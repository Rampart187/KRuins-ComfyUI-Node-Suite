KRuins Prompt Building Companion (PBC) | Free ComfyUI Custom Node

Build Better Prompts. Organize Your Wildcards. Create Without Limits.

Welcome to the KRuins Prompt Building Companion (PBC), a free custom ComfyUI node designed to simplify prompt creation, wildcard management, and reusable prompt presets, all from one convenient interface.

No more constantly switching between text editors, digging through wildcard folders, or manually copying the same prompts into your workflows.

With PBC, you can build prompts, manage your wildcard files, organize directories, import complete wildcard packs, and save your favorite prompts for instant reuse.

Create, edit, organize, and manage everything directly from PBC!

What Is the Prompt Building Companion?

PBC is a three-in-one prompt management tool featuring three dedicated tabs:

KEYWORDS: Quickly build prompts using customizable keyword buttons.

WILD CARDS: Browse, search, create, edit, delete, and import wildcard files without leaving ComfyUI.

PROMPTING: Create and save complete prompts as reusable presets, then insert them into your text encoder with a single click.

All three features work together to make prompt creation faster, easier, and more organized.

Key Features

  • Customizable keyword buttons
  • One-click keyword insertion
  • Wildcard folder browsing and searching
  • Direct wildcard TXT file editing
  • Create and delete wildcard files
  • Create, rename, and delete subdirectories
  • Smart folder renaming with automatic wildcard reference updates
  • Import individual TXT wildcard files
  • One-click ZIP wildcard pack importing
  • Automatic wildcard directory and folder creation
  • Refresh and change detection
  • Unlimited-length prompt presets
  • Import complete prompts from TXT files
  • Edit and delete saved prompt presets
  • Target text encoder selection
  • Undo and Copy controls
  • Persistent saved presets and settings

Compatibility and Supported Nodes

PBC is designed to work with ComfyUI text encoders and compatible wildcard-processing nodes.

It can be used with standard text prompt inputs, wildcard text encoders, wildcard resolvers, and other compatible nodes that accept prompt text.

PBC was specifically developed and tested to work with the KRuins Wildcard Batch and KRuins Show Text nodes.

These nodes provide a convenient workflow for inserting prompts, resolving wildcard references, and viewing the resulting text.

Important: PBC is a prompt-building and management companion. Wildcard expansion is performed by the compatible wildcard-processing node used in your workflow. Compatibility with third-party nodes depends on their supported text input and wildcard syntax.

Getting Started: Selecting Your Target

Before inserting keywords, wildcards, or prompt presets, select the text encoder or compatible prompt input you want PBC to control.

Once selected, the target node's name appears in the bottom target button.

You can then insert text directly into the selected target.

Use Clear Target to disconnect the current target and choose another.

Understanding PBC's Two Operating Modes

PBC has two operating modes, clearly identified by the status banner at the top of the interface.

PROMPT READY (Green)

This is the normal operating mode.

Use it to select keyword buttons, insert wildcard references, and load saved prompt presets into your target text encoder.

EDIT MODE (Red)

Edit Mode unlocks PBC's management features.

You can add or delete keywords, create and modify wildcard files, import files, manage folders, and create or edit prompt presets.

Click Edit to enter Edit Mode.

When finished, click Save to exit Edit Mode and return to Prompt Ready.

1. KEYWORDS: Build Prompts Faster

The Keywords tab provides a collection of clickable prompt keywords, including photography styles, camera angles, lighting, lenses, and other useful descriptors.

PBC includes starter keywords that you can customize to fit your own workflows.

Insert Keywords Into Your Prompt

Select your target text encoder, then click the keywords you want to use.

PBC inserts the selected text into your target prompt.

This is especially useful for quickly assembling photographic descriptions, cinematic styles, camera settings, and other frequently used prompt elements.

Undo Keyword Changes

Made a mistake or want to reverse your latest insertion?

Use Undo to restore the previous prompt state.

Add Your Own Keywords

  1. Click Edit.
  2. Enter a new keyword in the Add Keyword field.
  3. Click Add.
  4. Your new keyword appears as a button.
  5. Click Save when finished editing.

Delete Keywords

In Edit Mode, select the keyword buttons you want to remove.

Selected keywords are highlighted, and the Delete Selected counter displays how many are selected.

Click Delete Selected and confirm the operation.

Your keyword collection can grow and change with your creative workflow.

2. WILD CARDS: Complete Wildcard Management

The Wild Cards tab is one of PBC's most powerful features.

Instead of manually opening and editing TXT files in Windows Explorer, you can manage your wildcard library directly inside ComfyUI.

Browse Your Wildcard Directory

PBC displays your wildcard root directory, available subfolders, and wildcard files.

Click any subfolder to browse its contents.

Use Root to return to the main wildcard directory.

Insert Wildcard References

Click a wildcard button to insert its reference into your selected text encoder.

For example:

__appearance/KR_expression__

This reference can then be processed by your compatible wildcard resolver.

Find Wildcards Quickly

Use the Find Wildcard search field to locate files throughout your wildcard directory.

Search by filename, and PBC displays matching results along with their folder locations.

Create Your Own Wildcard Files

Enter Edit Mode to create new wildcard TXT files directly from PBC.

To create a wildcard:

  1. Navigate to the folder where you want to create it.
  2. Enter the new wildcard filename.
  3. Enter the wildcard values, one per line.
  4. Click Create Wildcard.

You can create wildcards in the root directory, any existing subfolder, or a nested subfolder.

For example:

wildcards/KR_example.txt
wildcards/appearance/KR_example.txt
wildcards/movie/horror/KR_example.txt

The wildcard is created in the directory you currently have selected.

Edit Existing Wildcards

Select an existing wildcard while in Edit Mode to open its contents.

You can add, remove, or modify the values directly in the editor.

Click Save Changes to update the file.

Delete Wildcard Files

Select the wildcard in Edit Mode and click Delete File.

PBC asks for confirmation before deleting the file.

Be careful when deleting wildcard files used by existing prompts, as their references may no longer resolve.

3. WILDCARD FOLDER MANAGEMENT

PBC includes a built-in Subdirectory Manager.

You can create, rename, and delete wildcard folders without opening Windows Explorer.

Create a New Subdirectory

Enter a folder name and click Create.

The new folder becomes available in your wildcard directory.

Rename Existing Subdirectories

Select an existing folder and enter its new name.

Click Rename to begin the operation.

Smart Rename: Update Wildcard References

One of PBC's most useful management features is its ability to detect wildcard references affected by folder renaming.

When renaming a folder, PBC can identify matching wildcard references and offer to update them automatically.

For example, renaming:

country to country_renamed

may require changing references such as:

__country/KR_example__

to:

__country_renamed/KR_example__

PBC provides options to update matching references, rename the folder without updating references, or cancel.

It also displays the number of matching references and the files containing them.

This helps prevent broken wildcard references when reorganizing large collections.

Delete Subdirectories

Select the folder and click Delete.

PBC displays a confirmation showing how many files and subfolders will be permanently deleted.

Warning: Deleting a folder also deletes its contents. This operation cannot be undone.

4. IMPORT WILDCARDS: TXT OR ZIP

PBC supports two wildcard import methods.

Import Individual TXT Files

Select the directory where you want the file imported.

Enter Edit Mode, click Choose Files, select your TXT wildcard file, and click Import.

The file is imported into the currently selected wildcard location.

One-Click ZIP Wildcard Pack Import

Have an entire collection of wildcards?

Import the ZIP file directly into PBC.

There is no need to manually extract the archive or recreate its folder structure.

PBC can automatically create the missing wildcard root directory and extract the folders and TXT files from the archive.

This makes installing new wildcard packs significantly easier, especially for beginners.

Refresh Your Wildcard Library

Click Refresh after importing files or making changes outside PBC.

The interface checks for changes and reports newly added or removed wildcard files and folders.

If nothing has changed, PBC displays No changes.

Change Your Wildcard Directory

Click the yellow folder button beside the directory path to browse for another wildcard location.

Select your desired folder and use the directory controls to update PBC.

5. PROMPTING: Save and Reuse Complete Prompts

The Prompting tab allows you to build a personal library of reusable prompt presets.

Instead of repeatedly typing or pasting the same long prompts, save them once and reuse them whenever needed.

Create a New Prompt Preset

  1. Click Edit.
  2. Click Add New Preset.
  3. Enter a preset button name, up to 25 characters.
  4. Paste or type your full prompt.
  5. Click Save Prompt.

The prompt editor has no preset character-length limit, allowing you to store detailed prompts containing many wildcard references.

Insert a Saved Prompt

Return to Prompt Ready and click your saved preset button.

PBC inserts the saved prompt into your selected target.

Edit Existing Presets

Enter Edit Mode and select an existing preset.

You can modify its name or prompt contents.

Click Save Prompt to save your changes.

Import Prompt Presets From TXT

You can also import a complete prompt from a TXT file.

Click Import TXT and select the file containing your prompt.

PBC creates a new preset using the imported prompt text and a button name derived from the filename.

This makes sharing and installing prompt presets convenient.

Delete Saved Presets

Select a preset in Edit Mode and click Delete Selected.

Confirm the deletion to remove the preset.

Important: The Save Prompt and Import TXT controls remain visible outside the scrolling editor area, so you can access them even when working with long prompts.

6. REAL-WORLD WORKFLOW EXAMPLE

Here's an example of PBC working with the KRuins Wildcard Batch and Show Text nodes.

A saved horror movie prompt can include wildcard references for a character's appearance, clothing, environment, expression, title, and tagline.

For example:

Professional photorealistic horror movie poster.

AMY is a beautiful __appearance/KR_age__
__appearance/KR_ethnicity__ woman with
__appearance/KR_eye_color__ eyes.

Wearing __movie/horror/KR_clothing__.

__movie/horror/KR_scene__.

Movie title: "__movie/horror/KR_title__"

Tagline: "__movie/horror/KR_tagline__"

PBC inserts the saved prompt into the selected text encoder.

KRuins Wildcard Batch then processes the wildcard references when the workflow runs, while KRuins Show Text can display the resulting resolved text.

This provides a straightforward way to create variations without rewriting your prompt every time.

8. TIPS AND BEST PRACTICES

Organize wildcards by category. Use folders such as appearance, clothing, environments, and photography to keep your library manageable.

Use descriptive preset names. Short names make your preset buttons easier to recognize.

Keep wildcard references consistent. When renaming folders, use Smart Rename to help update matching references.

Refresh after external changes. If you add or remove wildcard files outside PBC, click Refresh to update the displayed library.

Use the right Save button. In Edit Mode, use Save Changes for wildcard file edits and Save Prompt for prompt presets. The main Save button exits Edit Mode.

Back up important wildcard files. Before performing large renames or deletions, keep a backup of your wildcard directory.
